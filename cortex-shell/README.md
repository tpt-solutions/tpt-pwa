# cortex-shell (Tauri 2)

The optional desktop installer ([spec.txt](../spec.txt) §7): one native window containing the built PWA plus the Go `cortex-daemon` as a Tauri **sidecar**, with the `tpt://` protocol registered via the deep-link plugin. The PWA inside detects the daemon over `ws://127.0.0.1:9911` using its normal capability negotiation — the shell ships no PWA-specific logic.

## Layout

- `src-tauri/src/lib.rs` — boots the window, spawns the daemon sidecar, registers plugins (`shell`, `deep-link`).
- `src-tauri/tauri.conf.json` — bundle config; `externalBin: binaries/cortex-daemon`, deep-link scheme `tpt`, `frontendDist` points at `pwa/dist`.
- `scripts/prepare-sidecar.mjs` — places `cortex-daemon-<target-triple>` into `src-tauri/binaries/` (copies a real build if present, else a 0-byte placeholder for `cargo check`/dev).

## Build

```sh
pnpm install        # also runs prepare-sidecar
cargo check         # in src-tauri/ (or: pnpm tauri dev)
# release bundling needs a real daemon first:
go build -o ../cortex-daemon/bin/cortex-daemon-x86_64-pc-windows-msvc.exe ../cortex-daemon/cmd/cortex-daemon
pnpm build
```

Icons in `src-tauri/icons/` are generated by `pwa/scripts/generate-icons.mjs` (single source of truth for brand marks).
