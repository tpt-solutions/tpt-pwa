# cortex-shell (Tauri 2)

The optional desktop installer ([spec.txt](../spec.txt) §7): one native window containing the built PWA plus the Go `cortex-daemon` as a Tauri **sidecar**, with the `tpt://` protocol registered via the deep-link plugin. The PWA inside detects the daemon over `ws://127.0.0.1:9911/rpc` using its normal capability negotiation — the shell ships no PWA-specific logic.

## Layout

- `src-tauri/src/lib.rs` — boots the window, spawns the daemon sidecar, registers plugins (`shell`, `deep-link`).
- `src-tauri/tauri.conf.json` — bundle config; `externalBin: binaries/cortex-daemon`, deep-link scheme `tpt`, `frontendDist` points at `pwa/dist`.
- `scripts/prepare-sidecar.mjs` — places `cortex-daemon-<target-triple>(.exe)` into `src-tauri/binaries/`. It **fails loudly** when no daemon build exists (a 0-byte sidecar would ship an installer whose daemon can't start); opt into a placeholder for `cargo check` with `CORTEX_SIDECAR_ALLOW_PLACEHOLDER=1`. Runs automatically on `pnpm install` (the package's `prepare` script).

## Build

```sh
pnpm install        # runs prepare-sidecar — needs a real daemon binary (see below)
cargo check         # in src-tauri/ (or: pnpm tauri dev)

# release bundling: build the daemon for THIS machine's rust target first
TRIPLE=$(rustc -vV | sed -n 's/^host: //p')
(cd ../cortex-daemon && go build -o "bin/cortex-daemon-$TRIPLE$( [ "${TRIPLE#*windows}" != "$TRIPLE" ] && echo .exe )" ./cmd/cortex-daemon)
pnpm build
```

CI does exactly this dance (the `cortex-shell` job in `.github/workflows/ci.yml` builds the sidecar before `pnpm install`), so a green CI implies the instructions above work.

## Deep links (`tpt://`)

The deep-link plugin registers the `tpt` scheme on desktop; the Android intent filter lives in `cortex-android/app/src/main/AndroidManifest.xml`. Routes (`tpt://open`, `tpt://settings`, …) land in the PWA as URL fragments — see `MainActivity.handleDeepLink` for the Android twin.

## Icons

Icons in `src-tauri/icons/` are generated by `pwa/scripts/generate-icons.mjs` (single source of truth for brand marks).
